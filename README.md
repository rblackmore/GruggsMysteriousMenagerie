# Gruggs Mysterious Menagerie (GMM)

Automatic Companion Summoning

## Description
Automatically summons Favorite Companion pets as you travel the World of Warcraft.

## Features

### Companion Wardrobe for Transmogrifier

Create custom lists of companions for specific outfits.

### Welcome Pet Greeting:
If manually summoning a pet with `/gmsummon` command, a friendly chat message will welcome your companion to your side.
  
### Automatic Summoning:
Companions will be automatically summoned to your side when logging in, changing zones, respawning and several other event triggers.

### Pet of the Day:
If enabled, the addon will remember which pet was summoned first for the day, and continue summing them until midnight, or if you manually summon a different favorite pet.

## Configuration and Slash Commands
To Open the Add On Settings type `/gmm`
To Manually summon and welcome your pet to your side, type `/gmsummon`, for ease of use add to a macro
